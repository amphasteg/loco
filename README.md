# 🚂💨 Loco
A cross platform HTTP server library written for fun and learning C programming. 

## ❗Disclaimer
This project is mainly for fun. While I would enjoy making this "production-grade", I am a novice at C, and the primary objective of this project is to better myself at learning C. Feel free to hack around with things, open issues, or reach out to me if there's an opportunity to learn. Constructive criticism and feedback is welcome. I am no expert and I am open to expanding my knowledge and skillset where I can. 

## Goals
- Abstract platform specific functions surrounding sockets, threading, and processes for socket descriptors.
- Make the process of spinning up an HTTP server in C easier, as other libraries do, like ExpressJS.
- Learn new things

## Current Features
None, this project has just been started.
